# Weather App

## Setup
1. Get a free API key from https://openweathermap.org/api
2. Replace `YOUR_OPENWEATHER_API_KEY` in `script.js`.
3. Open `index.html` using Live Server.

## Features
- Search weather by city
- Temperature
- Humidity
- Wind speed
- Feels like
- Pressure

Deploy using GitHub Pages or Netlify.
